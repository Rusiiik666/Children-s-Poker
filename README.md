# Children's Poker

Heads-Up No-Limit Texas Hold'em against AI with a noir aesthetic.

Play one-on-one against "The Shadow" — an AI opponent that evaluates hand strength, considers pot odds, and occasionally bluffs.

## How to Play

1. Open [**Children's Poker**](https://rusiiik666.github.io/Children-s-Poker/) in any browser
2. Click **New Hand**, then **Post Blinds**
3. Choose your action: Fold / Check / Call / Raise (use the slider)
4. AI responds after a "thinking" pause

## Rules

- Texas Hold'em Heads-Up
- Blinds: 5/10
- Starting stack: 1000 chips
- Standard rounds: preflop, flop, turn, river, showdown
- Supported actions: fold, check, call, raise, all-in

## AI ("The Shadow")

- Evaluates hand across all 10 poker hand categories
- Considers pot odds before calling
- Bluffs ~8-15% of the time
- Pauses before each move for atmosphere

## Tech Stack

Pure HTML/CSS/JS — no dependencies or build tools required.
